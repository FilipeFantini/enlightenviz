# enlightenviz

A small server that draws dashboards written as code: SQL and chart
descriptions in Git, served with filters and live updates from a read-only
database connection.

**Status: design approved, first version in progress.** Nothing here is
usable yet. Read
[`docs/design.md`](docs/design.md): what it is for, what it will not do, its
security model, and the criteria by which the first version is judged or the
project abandoned.

Maintained by one person, with AI agents writing the code.
